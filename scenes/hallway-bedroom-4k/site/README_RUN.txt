NammaSpace hallway and bedroom viewer (4K capture)

Windows: double-click START_WINDOWS.bat (needs Python 3 installed). It starts a server that never caches, picks a free port and opens the link. Add --lan on the command line (START_WINDOWS.bat --lan) to also get a link for a phone on the same Wi-Fi.
Any OS: open a terminal in this folder and run  python serve.py  then open the link it prints. Opening index.html straight from the folder does not work.

Controls: click the scene, then W A S D to walk, Shift to run, mouse to look, Esc to free the mouse,
R to return to the door, M to show the collision grid, 1 and 2 for splat or mesh view.
Use the Detail buttons (250k, 500k) if the frame rate is low on an older laptop.
