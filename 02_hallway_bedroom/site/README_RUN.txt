NammaSpace bedroom viewer

Windows: double-click START_WINDOWS.bat (needs Python 3 installed). It opens http://localhost:8765/index.html.
Any OS: open a terminal in this folder and run  python -m http.server 8765  then open http://localhost:8765/index.html

Controls: click the scene, then W A S D to walk, Shift to run, mouse to look, Esc to free the mouse,
R to return to the door, M to show the collision grid, 1 and 2 for splat or mesh view.
Use the Detail buttons (250k, 500k) if the frame rate is low on an older laptop.
