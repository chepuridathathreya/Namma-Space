How to roam

Click inside the scene, then use W A S D to walk, the mouse to look, Shift to run, Space to jump and Esc to free the mouse. R returns to the door, M shows the collision grid and N the live map. Walls and furniture block you. Adding ?debug to the address shows a performance panel. On a laptop with two GPUs, set the browser to use the high-performance GPU for the best frame rate; the viewer lowers its detail automatically and says so if the frame rate is low.
