2. How to Roam

A guide dialog opens on the first visit to each scene. Click inside the scene, then use the controls in Table II. Walls and furniture block movement, using a collision grid built from the scan.

Table II
Viewer controls

InputAction
W A S D or arrow keysWalk
MouseLook around (click the scene first; Esc frees the cursor)
Shift, SpaceRun, jump
RReturn to the door
1, 2Splat view, mesh view (only scenes that have one)
M, NCollision grid overlay, live map

Adding ?debug to the address shows a performance panel. On a laptop with two GPUs, set the browser to use the high-performance GPU for the best frame rate. The viewer lowers its detail at start-up and says so if the frame rate is low.
