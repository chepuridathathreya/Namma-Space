Rebuild a model

git clone https://github.com/chepuridathathreya/Namma-Space
cd Namma-Space
pip install -r requirements.txt
python run_all.py --check          # lists anything missing
python run_all.py --test           # bundled sample, short training
python run_all.py --video my_walkthrough.mp4

Requirements: Linux or WSL2, NVIDIA GPU with 16 GB or more, 20 GB free disk, ffmpeg, COLMAP 3.9 or newer, nerfstudio with gsplat (requirements-train.txt).

Tested: preparation and finishing on Windows, training on Linux in our two-machine setup, the requirement check and finishing step on the bundled sample. Not yet tested: the one-machine training run on a separate clean GPU machine.
